# Assets

These files are not in the repository. Copy them here yourself before running or publishing the game.

| File | Role |
| --- | --- |
| `cursor.png` | Custom mouse pointer. A dark arrow on a transparent background, cropped to the glyph. The game draws it with the tip at the mouse, about 50 px on the long side. |
| `map.png` | Full-window scene. A wide isometric (or similar) landscape, around 2560×1600; it is scaled to fit the window with letterboxing. |
| `miserable.ttf` | HUD typeface for the FPS counter and key legend. Any readable TTF works; a condensed display font matches the original look. |
| `ambient.wav` | Looping background audio. Stereo PCM (for example 48 kHz) is fine; keep the file reasonably small if you substitute. |
